Acesso para todas as pessoas

Acessibilidade
é fazer parte.

O Ciclo reúne recursos que ajudam pessoas com diferentes necessidades a navegar, ler e compreender o conteúdo. Conheça cada opção e experimente os controles disponíveis no topo da página.

01 · Navegação

Acessibilidade

Recursos de navegação por teclado, foco visível e link para pular direto ao conteúdo ajudam pessoas que usam leitores de tela ou não utilizam mouse.

Como usar

Pressione Tab para percorrer links e controles; use Enter para ativar. Ao começar, “Pular para o conteúdo principal” evita repetir a navegação.

02 · Leitura

Alteração de tamanho de texto

Aumente ou reduza o texto para encontrar um tamanho confortável. Isso pode facilitar a leitura para pessoas com baixa visão ou dificuldades de leitura.

Como usar

Abra ♿ Acessibilidade no topo e escolha A+ Texto para aumentar ou A− Texto para diminuir. O ajuste acompanha a navegação nesta página.

03 · Visibilidade

Alto contraste

Reforça a diferença entre elementos e sublinha links para ajudar pessoas com baixa visão ou daltonismo a identificar informações e ações.

Como usar

No painel ♿ Acessibilidade, ative Alto contraste. Observe como textos, links e contornos ficam mais destacados.

04 · Conforto visual

Modo escuro

Usa uma paleta escura para reduzir o brilho da tela em ambientes pouco iluminados. A preferência fica salva neste dispositivo.

Como usar

Selecione ☾ Modo escuro no topo da página. O mesmo botão alterna de volta para o modo claro.

05 · Língua brasileira de sinais

VLibras

O VLibras traduz conteúdos digitais para a Língua Brasileira de Sinais (Libras), apoiando pessoas surdas que se comunicam por essa língua. A tradução automática pode ter limitações.

Como usar

Ative o botão flutuante do VLibras no canto da tela e selecione um trecho para ver a tradução em Libras. Atalho: Alt + Shift + L.

Os controles de texto, contraste e tema podem ser combinados. Use “Restaurar padrão” no painel para voltar às preferências iniciais.
