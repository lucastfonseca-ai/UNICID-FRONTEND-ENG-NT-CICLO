## ▌01. ◈ SOBRE O PROJETO

O **Ciclo** é um protótipo de página web desenvolvido por um grupo de estudantes do curso de **Engenharia de Software**, com foco no aprendizado de desenvolvimento Front-End e no tema **Sustentabilidade e Impacto Social**.

A proposta do projeto é explorar como a tecnologia pode ser utilizada para apresentar temas relevantes à sociedade por meio de uma experiência digital organizada, acessível e visualmente agradável.

Mais do que construir uma página web, o Ciclo representa uma etapa da nossa jornada acadêmica, na qual colocamos em prática os conhecimentos adquiridos em sala de aula, transformando ideias em uma interface funcional.

> ◈ A tecnologia constrói interfaces. A consciência transforma realidades.

## ▌02. ◈ CONCEITO E IDENTIDADE

### ♻️ Por que "Ciclo"?

O nome **Ciclo** remete à continuidade, à renovação e à responsabilidade compartilhada na construção de um futuro mais sustentável.

A identidade do projeto está associada à ideia de que nossas escolhas, ações e iniciativas fazem parte de um processo contínuo de transformação.

A sustentabilidade envolve não apenas a preservação dos recursos naturais, mas também a construção de uma sociedade mais consciente, inclusiva e comprometida com o bem-estar coletivo.

**Pilares conceituais do projeto:**

- 🌱 **Sustentabilidade:** conscientização sobre a importância de práticas responsáveis.
- 🌍 **Impacto social:** reflexão sobre como as ações humanas afetam comunidades e a sociedade.
- 💻 **Tecnologia:** utilização do desenvolvimento web para comunicar ideias e apresentar informações.
- 🔄 **Transformação:** valorização de iniciativas que contribuam para um futuro melhor.

## ▌07. ◈ EXECUTE LOCALMENTE

Deseja visualizar o código e executar o projeto em seu próprio computador?

Siga as etapas abaixo.

### Pré-requisitos

- Um navegador moderno.
- Um editor de código, como o [Visual Studio Code](https://code.visualstudio.com/).
- Git, caso deseje clonar o repositório pelo terminal.

### 1. Clone o repositório

```bash
git clone URL_DO_SEU_REPOSITORIO
```

Substitua `URL_DO_SEU_REPOSITORIO` pelo endereço HTTPS ou SSH do repositório do GitHub.

### 2. Entre na pasta do projeto

```bash
cd NOME_DA_PASTA
```

Substitua `NOME_DA_PASTA` pelo nome da pasta criada durante a clonagem.

### 3. Abra os arquivos

Abra a pasta no Visual Studio Code e localize o arquivo HTML principal da aplicação.

### 4. Visualize a página

Abra o arquivo HTML no navegador. Se preferir, utilize a extensão Live Server do Visual Studio Code para visualizar a página durante o desenvolvimento.

> Como o protótipo utiliza HTML e CSS, não é necessário instalar dependências de Node.js apenas para abrir uma página estática. Caso o repositório tenha outras ferramentas ou configurações, siga as instruções correspondentes.
